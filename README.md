# Новогодний подарок от Козочки

Сайт-визитка для продажи готовых новогодних подарочных наборов для детей.

## Структура

- `index.html` — разметка страницы
- `style.css` — стили
- `script.js` — логика (подстановка цены/контактов, эффект снега)
- `config.js` — **единственное место**, где меняются цена и контакты
- `assets/icons/` — иконки содержимого набора (SVG)

## Как изменить цену или контакты

Откройте [`config.js`](config.js) и поменяйте значения:

```js
window.SITE_CONFIG = {
  price: 600,                        // цена в рублях
  telegramUrl: "https://t.me/...",   // ссылка на Telegram
  phoneDisplay: "+7 977 981 08-33",  // телефон для отображения
  phoneHref: "tel:+79779810833",     // телефон для ссылки звонка
};
```

Изменения применятся на сайте автоматически после коммита и пуша в `main`.

## Деплой

Сайт автоматически собирается и публикуется на GitHub Pages при каждом
пуше в ветку `main` (см. `.github/workflows/deploy.yml`).

После первого пуша включите GitHub Pages в настройках репозитория:
**Settings → Pages → Build and deployment → Source: GitHub Actions**.
